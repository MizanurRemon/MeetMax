# 📱 My Android App

A simple Android application built with Kotlin and Jetpack Compose.

## Features
- User authentication
- MVVM architecture
- REST API integration
- Jetpack Compose UI

## Tech Stack
- Kotlin
- Jetpack Compose
- Hilt (DI)
- Retrofit
- Room
